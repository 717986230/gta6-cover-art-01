Neon Coast is an offline web app that turns your photos and a caption into multi-panel GTA-style cover art: pick a layout (Cover Story, Six Panel, Duo, Hero), drop a photo into each panel, frame it with drag and zoom, pick a sunset / neon / noir / palm colour grade per panel, and set bold condensed title lettering over the bottom. Exports PNG at 1080×1080, 1080×1350 and 1920×1080. Everything runs from static files in `app/` — no build step, no network, your photos never leave your machine. All artwork, shapes and gradients are original; the display font is Noto Sans Condensed Black under the SIL Open Font License (see `app/fonts/OFL.txt`).

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
